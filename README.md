# Step Size Strategies Web Application

An interactive Django web platform to explore and visualize step size strategies used in the
numerical solution of ordinary differential equations (ODEs). Developed as part of the master's
thesis of **Ersan Erdem** (Necmettin Erbakan University, 2019).

**Live site:** https://stepsizestrategies.pythonanywhere.com (English) ·
https://stepsizestrategies.pythonanywhere.com/tr/ (Türkçe)

- Picard theorem based strategy
- Error analysis based strategy
- Picard + error analysis strategy
- Linear and non-linear systems (2x2, 3x3, 4x4)
- Interactive Plotly charts, a summary panel and the full table of steps on every solver page
- Ready-made engineering examples (RLC circuit, mass–spring–damper, pendulum, Lotka–Volterra, SIR, SEIR …)
- Live LaTeX preview of the entered functions
- English and Turkish interface, light and dark theme, mobile friendly
- Excel export for registered users

## Requirements

- Python 3.12 or newer (the live site runs on Python 3.13)
- Django 6.1 and the packages in `requirements.txt`

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py test              # optional: run the test suite
python manage.py runserver
```

Open http://127.0.0.1:8000

## Production

Set the variables shown in `.env.example` (at least `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=0`,
`DJANGO_ALLOWED_HOSTS`), then:

```bash
python manage.py migrate
python manage.py collectstatic
```

and point your WSGI server to `stepsizestrategies.wsgi.application`.

## Search engines

- English pages live at the root (`/picardcl/`), Turkish pages under `/tr/` (`/tr/picardcl/`);
  every page links to its other-language version with `hreflang`.
- `/sitemap.xml` (both languages) and `/robots.txt` are generated by `strategies/seo.py`.
- Set `SITE_URL` (e.g. `https://stepsizestrategies.pythonanywhere.com`) so canonical links and
  social cards use the public address, and `GOOGLE_SITE_VERIFICATION`, `BING_SITE_VERIFICATION`,
  `YANDEX_VERIFICATION` to the codes from the webmaster tools.

## Translations

Turkish texts are in `strategies/locale/tr/LC_MESSAGES/django.po`. After editing the file run
`python manage.py compilemessages` (needs GNU gettext) to rebuild `django.mo`.

## Numerical notes

By default the application uses mathematically corrected versions of three details of the
original 2018 code (full rectangle for the bound M, matrix exponential for the local error,
correct total derivative of phi). Set `STEPSIZE_LEGACY_NUMERICS=1` to reproduce the original
numbers exactly.

All derivatives (f_t + f_x f for the scalar strategies, phi_t + J_x(phi)(AX + phi) for non-linear
systems) are computed symbolically with SymPy and then compiled with `lambdify`; no finite
differences are used. The bounds M, gamma and eta are numerical: M is the maximum over a 50x50 grid
of the rectangle, gamma and eta are evaluated at one point as in the original algorithm.
