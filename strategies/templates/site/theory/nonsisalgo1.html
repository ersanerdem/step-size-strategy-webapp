{% translate "Symbol" %}{% translate "Meaning" %}
\(\delta_{L}\)
{% if LANG == "tr" %}İstenen hata seviyesi.{% else %}The desired error level.{% endif %}
\(N\)
{% if LANG == "tr" %}\(A=(a_{ij})\in\mathbb{R}^{N\times N}\) matrisinin boyutu (bu sitede \(N=2,3,4\)); \(\varphi\in C^{1}([t_{0}-a,t_{0}+a]\times\mathbb{R}^{N})\).{% else %}The dimension of the matrix \(A=(a_{ij})\in\mathbb{R}^{N\times N}\) (\(N=2,3,4\) on this site); \(\varphi\in C^{1}([t_{0}-a,t_{0}+a]\times\mathbb{R}^{N})\).{% endif %}
\(Y_{i}\)
{% if LANG == "tr" %}\(i\). adımda elde edilen sayısal çözüm.{% else %}The numerical solution obtained in the \(i\)th step.{% endif %}

{% if LANG == "tr" %}\([t_{i-1},t_{i})\) üzerinde aşağıdaki problemin çözümü:{% else %}The solution of the following problem on \([t_{i-1},t_{i})\):{% endif %}\[Z'(t)=AZ(t)+\varphi(t,Z(t)),\ Z(t_{i-1})=Y_{i-1}\]
\(\alpha\)
{% if LANG == "tr" %}\(A\) matrisinin elemanlarının mutlak değerce en büyüğü:{% else %}The largest absolute value of the entries of \(A\):{% endif %}\[\alpha=\max_{1\leq i,j \leq N}|a_{ij}|\]
\(\beta_{i-1}\)
{% if LANG == "tr" %}Çözüm bileşenleri için bir üst sınır:{% else %}An upper bound for the components of the solution:{% endif %}\[\max_{1\leq i,j \leq N}\Big(\sup_{\tau_{i}\in[t_{i-1},t_{i})}|z_{j}(\tau_{i})|\Big)\leq\beta_{i-1}\]
\(\gamma_{i-1}\)
{% if LANG == "tr" %}\(\varphi\) için bir üst sınır:{% else %}An upper bound of \(\varphi\):{% endif %}\[\max_{1\leq j \leq N}\left(\sup_{\tau_{i}\in[t_{i-1},t_{i})}\left|\varphi_{j}(\tau_{i},z(\tau_{i}))\right|\right)\leq\gamma_{i-1}\]

{% if LANG == "tr" %}\(d\varphi/dt\) için bir üst sınır:{% else %}An upper bound of \(d\varphi/dt\):{% endif %}\[\max_{1\leq j \leq N}\left(\sup_{\tau_{i}\in[t_{i-1},t_{i})}\left|\frac{d\varphi_{j}}{dt}(\tau_{i},z(\tau_{i}))\right|\right)\leq\zeta_{i-1}\]
