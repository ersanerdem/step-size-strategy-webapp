{% translate "Symbol" %}{% translate "Meaning" %}
\(y_{i}\)
{% if LANG == "tr" %}\(i\). adımda elde edilen sayısal çözüm.{% else %}The numerical solution obtained in the \(i\)th step.{% endif %}
\(z(t)\)
{% if LANG == "tr" %}\([t_{i-1},t_{i})\) üzerinde aşağıdaki Cauchy probleminin çözümü:{% else %}The solution of the following Cauchy problem on \([t_{i-1},t_{i})\):{% endif %}\[z'(t)=f(t,z(t)),\ z(t_{i-1})=y_{i-1}\]
\(b_{i-1}\)
{% if LANG == "tr" %}\(|z-y_{i-1}|\) için bir üst sınır.{% else %}An upper bound of \(|z-y_{i-1}|\).{% endif %}
\(b_{0i-1}\)
{% if LANG == "tr" %}Arama dikdörtgeninin küçülen yarı genişliği:{% else %}The shrinking half-width of the search rectangle:{% endif %}\[b_{0i-1}=\min\{b_{0i-2},\ b_{i-1}\}\]
\(D_{i-1}\)
{% if LANG == "tr" %}Bir sonraki adımın arandığı dikdörtgen:{% else %}The rectangle in which the next step is searched:{% endif %}\[D_{i-1}=\{(t,z): |t-t_{i-1}|\leq a,\ |z-y_{i-1}|\leq b_{0i-1}\}\]
\(M_{i}\)
{% if LANG == "tr" %}\(|f|\) için \(D_{i-1}\) üzerinde bir üst sınır:{% else %}An upper bound of \(|f|\) on \(D_{i-1}\):{% endif %}\[\max_{(t,z)\in D_{i-1}}|f(t,z)|\leq M_{i}\]
